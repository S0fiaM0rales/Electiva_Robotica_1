## Estructura del Proyecto
El taller está dividido en tres secciones principales:

* **Seccion_A_Sin_Interaccion:** Operaciones matemáticas, conversión de coordenadas, cálculos de RTD PT100 y matrices de rotación sin interacción directa del usuario en consola.
* **Seccion_B_Con_Interaccion:** Programas que requieren el ingreso de datos por parte del usuario (teclado) para cálculos de potencia, volúmenes y selección de tipos de robots.
* **Seccion_C_Graficas:** Implementación de gráficas 2D y 3D utilizando bibliotecas de Python para visualizar funciones de transferencia, circuitos RC y contornos.
